# 브라우저/VTube Studio 아바타 방송 예제

약 7초의 결과 화면 예제입니다. 머리 방향과 눈·입 상태 변화를 관찰할 수 있습니다.

| 파일 | 용도 |
| --- | --- |
| `example.mp4` | H.264, 무음, 720px 너비, 웹 재생용 MP4 |
| `poster.jpg` | 동영상 재생 전 표시할 미리보기 |

## 공개본 편집

원본 음성·메타데이터를 제거하고 검은 여백과 화면 아래쪽 일부를 잘랐습니다. 원본 파일명, 개인 PC 경로, 원본 영상은 게시하지 않습니다. 게임 배경이 포함된 결과 화면이며 캐릭터 원본 에셋 또는 게임 자료의 재사용 권한을 제공하지 않습니다.

## 사용 안내

블로그의 「브라우저 아바타를 VTube Studio 기반 방송 아바타로 개량하기」 프로젝트 글에서 재생합니다. 영상은 실행 프로그램이 아니므로 이 MP4를 OBS에 넣는 것만으로 실시간 얼굴 추적이 되지는 않습니다. 실시간 방송은 VTube Studio Public API와 연결된 실제 아바타 앱의 로컬 방송 페이지를 브라우저 소스로 추가합니다.

## 검증 범위

눈·입·방향의 짧은 화면 변화만 관찰했습니다. 실제 입력 장치, 추적 동기화, 150프레임 전체, 연결 복구 및 장시간 송출 안정성은 이 영상만으로 확인할 수 없습니다.
