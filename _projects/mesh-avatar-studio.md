[Mesh Avatar Studio](https://github.com/shinshin86/mesh-avatar-studio)를 기반으로 한 장의 캐릭터 일러스트를 움직이는 **2D 메쉬 아바타**로 제작하고 있다. 눈·입 표정, 고개와 상체 움직임, 머리카락 물리를 추가하고 일반 사용자용 실행 앱까지 만들었다. Cubism 모델을 생성하거나 VTube Studio의 모델 목록에 설치하는 방식은 아니다.

**이번 개발 프로젝트의 저장소는 현재 비공개이며, 품질 검증과 공개 준비를 마친 뒤 공개할 예정이다.**

## 지금까지 만든 것

제작 흐름은 **일러스트 → 표정 그림과 숨은 영역 복원 → 독립 파츠 분리 → 관절·물리 설정 → 자세 검토 → 실행 앱**이다.

- 얼굴·목·몸통·팔·머리카락·모자·옷깃을 **14개 독립 파츠**로 구성했다. AI가 만든 소재도 원본과 합성 결과를 비교하며 보완했다.
- 별도 실기 시험에서 **iPhone → VTube Studio → 로컬 앱**으로 고개·눈·입 추적값이 전달되는 것을 확인했다.
- **Windows portable 앱**을 제작했다. Node.js·Python을 별도로 설치하지 않고 실행하며, 감도 저장·재연결·트레이 실행·OBS용 투명 출력 페이지를 제공한다.

## 겪었던 문제와 대응

| 문제 | 적용한 해결 방법 |
| --- | --- |
| 머리카락을 움직이면 옷과 주변 그림도 함께 움직임 | 단순 잘라내기에서 독립 RGBA 소재로 전환하고 가려진 몸통·어깨를 복원했다. |
| 움직인 파츠와 원래 그림이 겹쳐 두 개처럼 보임 | 밑그림에 남은 중복 영역을 정리하고 파츠별 그림의 소유 영역을 구분했다. |
| 목과 팔이 늘어나거나 어깨 연결이 어긋남 | 부모·자식 연결과 회전 중심을 적용하고 어깨 위치를 보정했다. 옷깃은 몸통에 연결했다. |
| 터미널 실행과 방송 페이지별 연결 관리가 번거로움 | 더블클릭 앱이 추적을 한 번 관리하고, 출력 페이지가 같은 값을 받도록 구성했다. |

이 대응으로 큰 중복·동반 이동·관절 늘어짐을 줄였지만, 모든 자세의 시각 품질이 완성된 것은 아니다.

## 이번 검토에서 남은 과제

- **머리카락 형태 복원:** 원본보다 귀 뒤·어깨 위가 많이 비어 있다. 옆머리와 뒷머리의 볼륨을 먼저 복원해야 한다.
- **눈·입의 연속성:** 약 9.87초에 열린 눈과 감긴 눈이 겹친다. 입도 타원형 크기 변화에 치우쳐 있으며, 현재 실시간 입력에서는 둥근 입용 그림을 선택하지 못한다.
- **접합과 회전:** 턱 아래 각진 경계를 보완하고, 평면 기울임을 넘어 방향에 따른 얼굴·상체 형태와 가림 관계를 설계해야 한다. 머리카락 내부 가닥의 반응도 세분화할 계획이다.

다음 순서는 **원본 형태 복원 → 눈·입 전환 → 목 접합 → 회전 자세 → 머리카락 물리 → 실제 방송 검증**이다. 파일·좌표 검사가 통과해도 자연스러운 그림이 보장되지는 않으므로, 원본 비교와 전환 프레임 심사를 강화한다.

원본 일러스트·분리 소재·실행파일·인증 정보·개인 작업 경로는 이 글에 포함하지 않았다. 현재 공개하는 것은 개발 기록과 시연용 영상이다.
