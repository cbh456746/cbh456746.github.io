**목표는 글을 읽던 자리에서 PPT 슬라이드를 한 장씩 넘겨 보는 것이다.** 슬라이드 전환 애니메이션과 자동 재생은 사용하지 않는다. 이 문서는 앞으로 만들 기능의 사양이며, **현재 블로그에서 뷰어가 이미 작동한다는 뜻은 아니다.**

## 독자에게 보일 화면

글 본문 안에 **현재 슬라이드 한 장 → 제목과 설명 → 툴바** 순서로 보여 준다. 툴바에는 `이전 · 3 / 12 · 다음 · 크게 보기` 네 요소가 놓인다.

**이전·다음**은 한 장씩 이동한다. 첫 장에서는 이전, 마지막 장에서는 다음 버튼이 비활성화된다. **현재 장수**는 `3 / 12`처럼 표시한다. **크게 보기**는 현재 장을 화면에 맞춰 확대한 뒤 닫고 원래 읽던 자리로 돌아오게 한다. 전환 효과 없이 이미지만 즉시 바뀐다.

휴대폰에서는 슬라이드가 본문 너비에 맞게 줄어든다. 원본의 글씨가 작으면 크게 보기에서 확인할 수 있어야 한다. 모든 장의 비율은 원본을 유지하며 화면 폭 때문에 잘리지 않게 한다.

## 어떻게 만들까

브라우저에서 PPTX 파일 자체를 재생하는 방식 대신, **게시 전에 슬라이드를 각각 이미지로 변환**한다. 글에는 이미지 목록을 전달하고 작은 JavaScript가 현재 장만 표시한다. 별도 서버, 공개 업로드 창, 외부 프레젠테이션 서비스는 필요하지 않다.

| 구성 요소 | 제안 위치와 역할 |
| --- | --- |
| 슬라이드 이미지 | `assets/images/presentations/<문서명>/slide-01.webp`처럼 순서대로 보관. 선·작은 글씨의 품질이 부족하면 PNG 사용 |
| 선택적 PDF | `assets/files/presentations/<문서명>.pdf`에 검수한 사본을 두고 다운로드 링크 제공 |
| 글의 슬라이드 목록 | 각 이미지 경로, 대체 텍스트, 제목·설명과 원래 가로세로 크기 기록 |
| 재사용 화면 | `_includes/slide-deck.html`에서 이미지와 툴바 생성 |
| 동작·모양 | `js/slide-deck.js`와 `css/site.css`에서 넘기기, 확대, 반응형·다크 모드 처리 |

저자가 글을 쓸 때는 슬라이드 목록을 한 번만 적고 공통 include를 호출하도록 한다. JavaScript가 실행되지 않으면 모든 슬라이드와 설명을 순서대로 읽을 수 있게 HTML을 먼저 만든다. JavaScript가 켜진 경우에만 한 장 표시와 툴바를 활성화한다.

원본 PPTX는 기본적으로 공개 저장소에 올리지 않는다. 공개용 이미지·PDF만 검수해 게시한다. 원본이 반드시 필요한 글에서는 별도 공개 판단을 거친다. 특히 발표자 노트, 숨긴 슬라이드, 문서 속성, 주석과 포함된 이미지의 공개 범위를 확인한다. [Microsoft의 문서 검사 안내](https://support.microsoft.com/en-gb/office/collab-files/remove-hidden-data-and-personal-information-by-inspecting-documents-presentations-or-workbooks?nochrome=true)를 참고한다.

## 읽기와 접근성

툴바는 실제 `<button>`으로 만들고 Tab으로 이동하며 Enter·Space로 조작할 수 있어야 한다. 장을 바꿔도 키보드 초점은 누른 버튼에 남긴다. 현재 장수의 변경은 화면 읽기 도구에도 알린다. 확대 화면은 Esc로 닫고, 닫은 뒤 초점을 크게 보기 버튼으로 돌린다. [W3C의 슬라이드 탐색 지침](https://www.w3.org/WAI/tutorials/carousels/functionality/)을 따른다.

각 장에는 내용이 드러나는 대체 텍스트와 짧은 설명을 붙인다. **핵심 정보가 슬라이드 이미지에만 있으면 안 된다.** 중요한 문장·도표의 결론은 글의 텍스트에도 적어야 화면 읽기 도구, 검색과 블로그의 AI 참조 내보내기에서 읽을 수 있다. 이미지 속 글자를 자동으로 추출했다고 가정하지 않는다.

첫 장은 바로 보이게 하고 뒤의 이미지는 필요할 때 불러온다. 이미지 크기를 HTML에 기록해 화면이 뛰지 않게 하며, 실제 자료의 화질을 보면서 파일 크기를 조절한다. 외부 iframe과 제삼자 스크립트는 기본 사양에 넣지 않는다.

## 구현 완료를 판단하는 기준

1. Notes·Research·Projects 글 중 한 곳에 같은 뷰어를 삽입할 수 있다. 본문과 기존 다크 모드가 깨지지 않는다.
2. 이전·다음·장수·크게 보기가 데스크톱과 좁은 휴대폰 화면에서 작동한다. 첫 장과 마지막 장의 버튼 상태가 정확하다.
3. 키보드만으로 넘기고 확대 화면을 닫을 수 있다. JavaScript를 끄면 슬라이드와 설명을 순서대로 읽을 수 있다.
4. 공개된 슬라이드 이미지·선택적 PDF의 링크가 유효하고, 글의 핵심 설명이 AI 참조용 본문에도 남는다.
5. 게시 파일의 저작권, 숨은 내용, 개인정보, 이미지 품질과 다운로드 크기를 검수한다.

**다음 단계:** 실제 PPTX 한 개를 샘플로 변환한 뒤, 작은 글씨가 휴대폰에서 얼마나 읽히는지 먼저 확인한다. 그 결과를 기준으로 뷰어를 구현하고 위 항목을 검증한다.
