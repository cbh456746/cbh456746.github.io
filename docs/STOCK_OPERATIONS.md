# Stock / Stars 운영 안내

Stock은 소유자가 고른 미국 상장 주식·ADR·ETF만 보여주는 공개 페이지입니다. `/stock/`의 왼쪽 Stars 목록을 휠 또는 터치로 스크롤하고 종목 이름을 누르면 오른쪽 차트와 그 종목의 분석 글 카탈로그가 바뀝니다. 모바일에서는 목록 아래에 선택한 내용이 나타납니다.

화면 상단에는 `STOCK` 제목만 표시합니다. Watchlist 검색창에 이름·티커·거래소 포함 기호를 입력하면 타이핑하는 동안 해당 문자를 포함한 Stars만 남습니다. 검색어를 지우면 전체 목록이 다시 나타납니다. 선택한 종목의 차트는 검색 중에도 그대로 유지됩니다.

정렬 메뉴에서 **기본 순서**, **이름 ↑**, **이름 ↓**, **내 순서**를 고를 수 있습니다. **순서 편집**을 누르면 내 순서로 전환되며 각 종목에 위·아래·맨 아래(⤓) 버튼이 나타납니다. ⤓를 누르면 그 종목이 목록 끝으로 한 번에 이동합니다. 원하는 순서로 옮긴 다음 **편집 완료**를 누릅니다. 바꾼 순서는 이 브라우저의 사이트 저장소에 공개 티커 배열로만 저장되며, 새로고침 후에도 유지됩니다. 맨 아래 종목의 ↓·⤓ 버튼은 비활성화됩니다. 편집 중 **초기화**를 누르면 저장된 개인 순서가 지워지고 저장소의 등록순으로 돌아갑니다. 검색 중에는 순서 편집을 잠시 사용할 수 없으므로 검색어를 먼저 지웁니다. 브라우저 저장이 차단되면 현재 화면에서만 이동하고, 사이트 데이터를 지우면 개인 순서가 초기화됩니다. 새로운 Stars는 기존 개인 순서의 뒤에 붙습니다. 다른 방문자의 순서나 공개 기본순서는 바뀌지 않습니다.

## 현재 데이터의 의미

- Stars 정본은 `_data/stock-stars.yml`입니다. 이 파일의 순서가 공개 기본순서입니다. 방문자의 개인 순서 편집은 항목 추가·삭제나 저장소 수정이 아닙니다. 공개 기본순서를 바꾸려면 소유자가 원하는 순서를 AI에 전달하고, AI가 이 파일을 수정·검증·게시합니다.
- 최초 목록은 소유자가 제공한 관심 종목 이미지의 미국 상장 항목 24개입니다. 현대차·오리온홀딩스·대한항공은 코스피 항목이므로 제외했습니다. 쿠팡은 회사의 소재와 무관하게 NYSE 상장 종목이라 포함했습니다.
- 이미지에 보이는 원화 가격, 장전 표시, 변동 수치를 저장하거나 USD로 환산하지 않았습니다. 화면의 가격·등락과 차트는 방문 시 TradingView 위젯이 제공합니다. TradingView는 미국 주식 공개 위젯에 지연 데이터만 제공한다고 명시합니다. 위젯이 차단되거나 장애가 나면 표시되지 않을 수 있습니다. [TradingView 데이터 안내](https://www.tradingview.com/widget-docs/faq/data/)와 [위젯 안내](https://www.tradingview.com/widget/)를 확인합니다.
- Kraft Heinz는 2026-09-14 Nasdaq에서 NYSE로 거래소를 옮겨 현재 기호가 `NYSE:KHC`입니다. [회사 발표](https://ir.kraftheinzcompany.com/news/kraft-heinz-to-transfer-stock-exchange-listing-to-nyse/0f3f933b-8f7f-4c91-a860-0cb6457f9d6f)와 [SEC 공시](https://www.sec.gov/Archives/edgar/data/1637459/000163745926000057/khc-20260824.htm)를 근거로 Stars를 갱신했습니다. 기존 `NASDAQ:KHC` 공유 주소와 방문자 브라우저에 저장된 개인 순서는 현재 공개 목록의 `NYSE:KHC`에만 대응시켜 유지합니다. 신규 종목을 등록하거나 거래소가 바뀌면 현재 상장 정보를 다시 확인합니다.
- 위젯은 외부 스크립트와 데이터 연결을 사용합니다. TradingView는 위젯 작동을 위해 방문자의 IP 주소, 포함한 페이지 URL, 위젯 종류, 표시 종목을 처리한다고 설명합니다. [공식 FAQ](https://www.tradingview.com/widget-docs/faq/general/). 이 사이트에 시세 API 키나 방문자 계정 권한은 두지 않습니다.
- 이 영역은 개인 분석 기록용입니다. 수치나 글을 주문 실행 또는 투자 자문으로 오인하지 않도록 작성일과 시세 시점을 구분합니다.

## Stars 추가·삭제

1. 소유자가 종목 이름과 가능하면 거래소·티커를 알려줍니다. AI는 현재 미국 상장 상태와 TradingView 기호를 확인합니다. 예를 들어 형식은 `NASDAQ:AAPL`, `NYSE:BRK.B`입니다. 코스피 종목은 넣지 않습니다.
2. `_data/stock-stars.yml`에서 `symbol`과 `name` 두 줄로 한 항목을 추가하거나 제거합니다. 이름은 표시용이며 HTML이나 프롬프트로 해석하지 않습니다. 원화 가격, 개인정보, API 키는 쓰지 않습니다.
3. `npm run validate`와 `git diff --check`를 실행하고 PC·모바일에서 목록, 차트, 기존 글 연결을 확인합니다. 종목을 삭제할 때 그 `stock_symbol`로 게시된 분석 글이 있으면 검사가 실패합니다. 글의 공개 유지·이전·삭제를 소유자와 정한 다음 처리합니다. Stars 밖 종목의 분석 글이 공개된 상태로 남지 않도록 합니다.
4. 요청에 따른 일반 커밋·푸시 후 같은 커밋의 Pages 배포와 실제 `/stock/` 화면을 확인합니다. 정적 페이지라 목록 변경은 배포 뒤 공개됩니다. 강제 푸시는 사용하지 않습니다.

### 페이지에서 티커 입력·삭제 버튼을 제공하려면

현재 방식은 소유자가 Codex에 티커 추가·삭제를 요청하고, AI가 미국 상장 여부·TradingView 기호·기존 분석 글을 확인한 뒤 저장소를 갱신합니다. 일반 방문자용 입력·삭제 버튼으로 공개 목록을 직접 바꾸는 기능은 정적 GitHub Pages만으로 안전하게 구현할 수 없습니다. GitHub 쓰기 토큰을 공개 JavaScript에 넣거나, 누구나 호출할 수 있는 쓰기 엔드포인트를 두면 목록 변조와 저장소 침해 위험이 생깁니다.

향후 화면 안에서 관리하려면 소유자 인증이 있는 별도 관리 기능과 서버 측 권한 확인·요청 검증·변경 기록·배포 경로가 필요합니다. 방문자 개인의 브라우저에만 저장되는 목록은 구현할 수 있지만, 소유자의 공개 Stars와 종목별 분석 목록을 바꾸지는 못합니다. 현재 요청에서는 공개 추가·삭제 버튼을 만들지 않으며 기존의 AI 갱신 방식을 유지합니다.

## 차트 기본값과 다크 모드

현재 차트는 **지난 1년(12M)** 범위와 **Area** 유형을 기본값으로 사용합니다. `Line with markers`와 `Area`는 TradingView의 서로 다른 차트 유형이므로 한 차트에 두 유형을 동시에 기본값으로 지정하지 않습니다. 사용자는 위젯의 차트 유형 메뉴에서 다른 유형으로 변경할 수 있습니다. [차트 유형 안내](https://www.tradingview.com/support/solutions/43000703407-chart-types-available-on-tradingview/), [위젯 설정](https://www.tradingview.com/widget-docs/widgets/charts/advanced-chart/).

블로그 좌상단의 달·해 버튼으로 화면을 전환하면 TradingView 차트와 Stars 시세 위젯도 선택한 테마로 다시 불러옵니다. 어두운 화면의 시세 위젯은 투명 배경을 끕니다. 투명 배경과 브라우저의 `color-scheme: dark`를 함께 사용하면 위젯 카드가 흰색으로 표시되는 현상을 실제 화면과 로컬 비교에서 확인했기 때문입니다. 첫 방문의 기본값은 밝은 화면이고, 선택은 이 브라우저의 사이트 저장소에만 기록됩니다. 차트의 12M/Area 기본값은 유지되지만 테마를 바꾸면 외부 차트가 새로 로드되므로 차트 안에서 임시로 바꾼 확대 범위나 유형은 초기화될 수 있습니다. 위젯이 차단된 환경에서는 가격·차트가 표시되지 않을 수 있습니다.

## 종목 분석 글 추가

분석 원문은 `_stock_analysis/`에 Markdown으로 저장하고 `stock_symbol`을 Stars와 **완전히 같은** 거래소 포함 기호로 지정합니다. 파일 이름은 영문 소문자와 하이픈을 사용합니다. 필수 정보는 `title`, 실제 작성 `date`, `tags`의 `Stock`, `stock_symbol`, 다른 글과 동일한 검토된 `context` 요약입니다. `_config.yml`의 기본 레이아웃이 `/stock/analysis/파일이름/`을 만듭니다. 아래는 게시물이 아닌 작성 형식입니다.

```yaml
---
title: "실제 글 제목"
subtitle: "무엇을 분석했는지 한 줄"
date: 2026-11-05 12:00:00 +0900
tags:
  - Stock
stock_symbol: NASDAQ:AAPL
context:
  summary: "검토한 글의 한 줄 요약"
  reviewed_on: '2026-11-05'
  findings: []
  limits: []
  followups: []
  keywords: []
  related: []
---
```

실제 글에는 자료 출처, 관찰 시점, 가정과 반대 근거, 불확실성을 적습니다. 분석 글을 쓰지 않은 Stars는 카탈로그에 “아직 공개한 분석 글이 없습니다”라고 나옵니다. Stock 글은 Stock 전용 카탈로그에서 찾으며, 현재 전체 Archive·검색·RSS·AI 참조 내보내기에는 자동 포함되지 않습니다. 이 발견 경로를 넓히려면 별도 요청과 RSS 보류 결정을 먼저 확인합니다.

## 화면·보안 구현

`stock.md`는 Jekyll이 목록과 종목별 카탈로그를 생성합니다. `js/stock.js`는 현재 Stars 목록에 **포함된 기호만** URL에서 선택하고, 해당 차트 하나와 보이는 시세 위젯을 로드합니다. 임의의 쿼리 문자열이나 브라우저에 저장된 순서가 새로운 종목 요청으로 연결되지 않게 합니다. 개인 순서 복원 시에도 현재 공개 목록에 없는 기호를 버리고 새 기호를 끝에 붙입니다. 검색은 이미 공개된 목록을 화면에서 숨기는 기능이며 외부 검색 요청을 보내지 않습니다. 선택 링크는 브라우저 뒤로 가기를 지원합니다. `css/site.css`는 PC의 스크롤 목록과 모바일의 세로 배치를 담당합니다.

Watchlist 행은 현재 TradingView 단일 시세 내용의 관찰된 높이 69px에 맞춰 공간을 예약합니다. iframe 자체는 더 크게 생성될 수 있으나 아래쪽 빈 부분만 가립니다. 위젯이 느리게 로드되어도 행 높이가 갑자기 바뀌지 않도록 하며, 제공자가 내부 크기를 바꾸면 PC와 좁은 화면에서 숫자·출처 표시가 잘리는지 확인한 후 이 값을 조정합니다.

외부 위젯 코드의 공급망·가용성 위험은 남습니다. 공급자의 스크립트 주소를 임의로 바꾸지 말고, 시세가 없는 상태를 허위 가격으로 대체하지 않습니다. 분석 글과 Stars 이름은 외부에서 받은 프롬프트나 HTML을 그대로 복사하지 않고 출처와 공개 범위를 검수합니다.
