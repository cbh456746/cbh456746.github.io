## 현재 파일 정리

## 영상 예제

기존 브라우저/VTube Studio 프로젝트에 약 7초 무음 영상, 포스터와 안내를 추가했다. 원음과 원본의 개인 메타데이터는 공개하지 않는다. 눈·입·방향의 화면 변화는 관찰했지만, 영상만으로 입력 장치·동기화·전체 프레임·연결 복구·장시간 송출을 검증했다고 서술하지 않는다.

## 과거 이력 삭제 상태

**현재 파일 정리와 과거 이력 정화는 서로 다른 작업이다.** 소유자의 명시적 승인 후, 2026-10-01에 정화된 163개 커밋을 `force-with-lease`로 공개 main에 적용했다. 현재 파일 트리가 교체 전과 동일함을 확인했고, 과거 소개·연락처·개인 PC 경로와 비공개 작성자 연락처를 제거했다. 계정에 연결되는 GitHub 비공개 이메일을 사용하며 GitHub 서비스 커미터 표시는 유지했다. 155개 기존 커밋 서명은 내용 변경으로 유지할 수 없었다.

main에서 도달 가능한 이력의 패턴 검사를 통과했다. 이력 교체가 GitHub의 오래된 커밋 캐시, Actions·배포 기록, 다른 사람의 복제본이나 검색엔진 사본까지 자동 삭제하지는 않는다. 해당 잔여 영역의 완전 삭제를 확인했다고 주장하지 않는다. 기존 복제본은 옛 이력을 다시 푸시하지 말고 정화된 main으로 재동기화해야 한다. 로컬 복구용 원본 이력은 공개 저장소에 올리지 않는다.
