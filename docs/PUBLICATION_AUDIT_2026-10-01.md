## 점검 범위

점검 시작 시 공개 main의 **162개 커밋과 415개 파일 버전**, 현재 문서·설정, 공개 이미지 메타데이터, 공개 브랜치·태그를 확인했다. 공개 브랜치는 main 하나이며 태그는 없었다. 이메일·이름·개인 PC 경로·대표 비밀값 패턴을 검사했다. 패턴 검사만으로 모든 형태의 개인정보를 검출했다고 보장하지 않는다.

## 현재 파일 정리

사용하지 않는 테마 소개·샘플 글·사진, 현재 Notes에 동일 본문이 있는 이전 글 6개, 중복 게시물 양식, 홈페이지 경로가 겹치는 이전 index.html을 제거했다. 기존 학습 노트·프로젝트·라이선스·운영 문서는 유지한다. 이전 테마의 도메인 파일과 공개 허용 범위 밖의 서비스 계정 식별값도 제거했다. 오래된 서비스워커는 등록 해제와 이전 캐시 삭제만 수행하도록 변경했다. PWA 아이콘의 텍스트 메타데이터는 픽셀을 바꾸지 않고 제거했다.

## 영상 예제

기존 브라우저/VTube Studio 프로젝트에 약 7초 무음 영상, 포스터와 안내를 추가했다. 원음과 원본의 개인 메타데이터는 공개하지 않는다. 눈·입·방향의 화면 변화는 관찰했지만, 영상만으로 입력 장치·동기화·전체 프레임·연결 복구·장시간 송출을 검증했다고 서술하지 않는다.

## 과거 이력 삭제 상태

**현재 파일 정리와 과거 이력 정화는 서로 다른 작업이다.** 과거 소개·연락처와 커밋 작성자의 비공개 연락처가 이력에 남아 있다. 정화된 이력을 별도 로컬 저장소에 준비하고 검사한다. 원격 이력 교체는 커밋 ID를 변경하므로 명시적 승인이 필요하다. 승인 전에는 공개 Git 이력에 이전 정보가 남아 있다. 이력 교체를 완료해도 GitHub의 캐시·포크·다른 사람의 복제본·검색엔진 사본까지 자동 삭제되지는 않는다.

## 확인 절차

콘텐츠 양식 검사, 개인정보 패턴 검사, 내부 파일 참조와 동영상 메타데이터 검사 후 게시한다. GitHub Pages 빌드와 배포 완료는 Actions 결과로 확인하며, 배포 후 소개·프로젝트·목록·검색·영상 재생을 점검한다.
