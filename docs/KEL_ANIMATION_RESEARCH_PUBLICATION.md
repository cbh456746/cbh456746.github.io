# KEL AI 애니메이션 연구 게시 기록

작업일: 2026-10-30, Asia/Seoul.

## 요청과 게시 범위

사용자는 자체평가를 외부 공개용 연구 글로 정리하고 GitHub 블로그 Research에 게시하도록 명시했다. 제작 워크플로우·모델·방법·RISE의 특징·실제 결과·목표 미달 원인·실제 프롬프트·후속 진단을 포함하며, 프롬프트 보이기/숨기기와 그림·스크린샷·동영상으로 가독성을 높이도록 요청했다. D-020은 이번 사례의 공개 승인과 한계를 기록한다.

본문: [`_research/eternal-return-ai-animation-study.md`](../_research/eternal-return-ai-animation-study.md).

공개 주소: [이터널리턴 AI 애니메이션 실험](https://cbh456746.github.io/research/eternal-return-ai-animation-study/).

기준 main은 `bed7540fd95a44abf1a244cb8471ac49720b2f1b`이며, 깨끗한 새 복제본에서 `codex/kel-animation-research` 브랜치로 작성했다. 기존 글과 홈페이지·프로필·서비스 설정·공통 레이아웃/CSS·RSS 정책은 수정하지 않는다. 공개 작성자는 BH CHOI와 GitHub noreply 주소를 사용한다. 일반 fast-forward 방식으로만 게시한다.

## 글과 공개 자료

- 15.667초, 24fps, 376프레임의 실제 최종 초안 MP4. 생성은 1024×576, 출력은 1920×1080 확대다. 임시 합성 음향을 포함하며 자동 재생하지 않는다.
- 설명 SVG 1개, 원화 보드·RISE 비평 표본·발사/시그니처/후일담 프레임·입력과 출력 비교 WebP, 개별 원화 WebP 8개, 영상 포스터. RISE 표본은 생성 결과와 명확히 구분하고 공식 영상으로 연결한다.
- 실제 프롬프트 27개의 네이티브 `<details>`: 최종 선택 9, 미채택 본 제작 5, 원화 확장/보정 9, 사전 시험 4. 공정 설정과 원화 갤러리를 포함한 본문 전체의 접이식 요소는 29개다. 기본 상태는 닫힘이며 사용자 입력으로 펼치고 접는다.
- 재현 ZIP 약 14.24 MiB: 메타데이터를 제거한 AI 입력 PNG 8장, 실제 API 그래프 18개, 원화 지시문 9개, 환경·실행·편집 JSON, README. 그래프의 출력 파일 접두사만 공개용으로 바꿨다.
- 원본 게임 영상·원작 캐릭터 자료·RISE 원본 영상/프레임·모델 가중치·개인 경로·인증 정보·비공개 원시 로그는 ZIP에 포함하지 않는다. 비교용 RISE 그림 1개는 글의 비평 자료로만 선별 공개한다.

주요 결론은 목표 미달이다. 형태 불안정·생략된 회전·화살/타격 연결 문제를 관찰과 가설로 나눴다. 공식 LTX 다중 스케일과 다른 단일 패스 설정, CFG 1의 부정 조건 해석, 복원과 부정 프롬프트가 함께 바뀐 Wan 재시도라는 교란 조건을 밝혔다. 모델 순위·RISE 도달률·완전 무료 제작을 입증한 것처럼 쓰지 않았다. 후속 평가는 아직 실행하지 않은 제안으로 구분했다.

## 게시 전 검사

`npm run validate`, `git diff --check`가 통과했다. 개인 작업 폴더에서 별도 검사 스크립트로 본문과 include를 결합해 링크·HTML·파일을 확인했다. 이 스크립트와 컴포넌트 미리보기는 공개 저장소에 넣지 않는다.

확인한 내용:

- 본문 이미지 15개, 목차 앵커 7개, 자료 링크 58개를 검사했다. 크기·alt·실제 파일과 SVG XML이 유효하다.
- 접이식 요소 29개가 기본 닫힘이며, 프롬프트 include의 27개는 원문을 HTML 이스케이프했다.
- ZIP 항목 39개와 CRC, 18개 그래프의 원본 일치(출력 접두사 제외), 안내 이미지의 포함 여부를 확인했다.
- 입력 PNG 8장의 디코딩 RGB 해시가 원본과 일치한다. 공개 WebP/PNG에는 EXIF·XMP·ICC·comment가 없다.
- 공개 MP4의 A/V 패킷 해시는 원본과 일치한다. 메타데이터만 제거한 remux이며 재생 내용은 바꾸지 않았다.
- 공개 텍스트·ZIP 텍스트의 개인 경로·연락처·토큰 패턴에서 발견 0건. 이 패턴 검사만으로 모든 노출 위험이 배제된다는 뜻은 아니며, 자료 선택과 시각·본문 검토를 함께 했다.

로컬 Ruby/Bundler가 없어 로컬 Jekyll 빌드는 실행하지 않았다. MarkdownIt 컴포넌트 렌더는 Jekyll 검사로 간주하지 않는다. 로컬 미리보기 서버는 실행됐으나 브라우저의 loopback 접속이 실패했으므로 게시 전 브라우저 검수를 완료했다고 기록하지 않는다. 실제 Jekyll 빌드/RSS 검증은 기존 GitHub Actions에서, 화면과 재생 검증은 배포 후 공개 페이지에서 수행한다.

## 후속 범위

이번 게시가 새 애니메이션 개선본의 완성을 의미하지는 않는다. 실제 개선 제작은 본문의 통제 실험과 행동 가독성 기준을 별도로 통과해야 한다. 새 원본 자료나 다른 캐릭터 자산을 일괄 공개하는 승인으로 확대하지 않는다.
