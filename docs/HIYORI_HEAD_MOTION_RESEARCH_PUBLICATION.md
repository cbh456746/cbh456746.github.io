# Hiyori–Silver Braid 고개 회전 연구 게시 기록

작업일: 2026-10-26, Asia/Seoul.

## 요청과 공개 범위

사용자는 로컬 Hiyori 비교 연구를 더 심층적인 글로 확장해 GitHub 블로그 Research에 게시하도록 요청했다. 이어 비교분석 사진을 포함한 형식이 원하는 방향이라고 명확히 했다. 고개 회전·얼굴 찌그러짐·목과 상체의 가동을 우선하고 표정 분석은 보조 범위로 두었다.

정식 글은 [`_research/hiyori-silver-braid-head-motion-study.md`](../_research/hiyori-silver-braid-head-motion-study.md)이며 공개 주소는 [연구 본문](https://cbh456746.github.io/research/hiyori-silver-braid-head-motion-study/)이다. 기존 연구·프로젝트 소개를 복제하거나 덮어쓰지 않았다.

공개한 자료는 선별한 비교 사진의 웹용 내보내기 6개, 설명용 SVG 1개, 좌우 끝자세 집계 CSV 1개다. 캡처 전체, 원본 일러스트, 분리 소재, 모델·메시·UV·키폼 내부 데이터, 인증 정보와 개인 경로는 포함하지 않았다. 프로젝트 원본 저장소의 비공개 상태를 유지하며 본문에도 현재 비공개·추후 공개 예정임을 설명했다. 이번 공개 범위는 해당 글의 선별 비교 자료이며 다른 제작 자산의 일괄 공개 승인이 아니다.

## 비교와 연구 내용

- 376장 전체 개요 검토, 약 10초 촬영 간격, 암전/다른 화면 2장 제외라는 자료 조건을 설명했다.
- 세 실제 빌드의 39개 기하 상태와 추가 실제 렌더 14개를 근거로 했다.
- 원시 입력·내부 제어값·물리적 회전각의 차이, 모델별 가동 제한, 최종 가림 마스크의 미반영을 명시했다.
- 국소 압축·늘어남을 삼각형 변형의 특이값으로 설명하고, 전체 면적·뒤집힘 0만으로 품질을 승인할 수 없음을 설명했다.
- 가동범위 축소 렌더와 아직 제작·승인하지 않은 근본 교정 목표를 구분했다.
- 공통 두상 아래 방향별 보정, 앞뒤 가림, 목 연결, 중간/대각 자세와 연속 경로의 합격 기준을 정리했다.
- 공식 Cubism 얼굴 XY·확장 보간·표정 제작 자료를 연결했다. GUI 자동 리깅이나 비공개 Cubism 바이너리 해체를 수행했다고 주장하지 않았다.

## 작성·공개 파일 검수

새 본문은 14개 본문 절과 목차 앵커, 7개 비교·설명 그림을 포함한다. 기존 Research·VTuber·Live2D 태그를 사용했다. 이미지에는 설명 alt·크기·지연 로딩·원본 크기 보기 링크·개별 해석 한계 캡션을 넣었다. 전체 WebP 전송 크기는 약 1.13MB다.

`npm run validate`와 스테이징 diff 검사가 통과했다. 목차 14개와 대상 앵커, 이미지·집계 자료의 링크, CSV 6개 행과 수치 반올림을 확인했다. WebP 6개의 디코딩·크기와 EXIF/XMP/comment/ICC 부재를 확인했다. 설명 SVG는 XML로 파싱했다. 공개 파일의 개인 PC 경로·연락처·토큰/키·로컬 서버·비공개 자산 링크 패턴에서 발견 0건을 확인했다. 패턴 검사가 모든 노출 가능성을 보장하는 것은 아니므로 선택 이미지와 본문을 시각·내용 검토했다.

로컬 Ruby/Bundler 환경이 없어 로컬 Jekyll 빌드는 실행하지 않았다. 실제 Jekyll 빌드와 RSS 파싱은 기존 GitHub Pages Actions에서 확인한다. PC·모바일 검수에서는 방문 통계를 만들지 않도록 DNT와 외부 분석 요청 차단을 사용한다. 실제 모바일 하드웨어나 모델의 실제 VTS/OBS 검증과는 구분한다.

## 이력과 게시 방식

기존 로컬 복제본은 개인정보 이력 정리 이전 상태였으므로 그대로 보존했다. 정화된 원격 main `f017cfd006bc2f58d1b7214e8c8e641d8c4c671f`에서 새 복제본과 `codex/` 작업 브랜치를 만들었다. 허용된 공개 작성자와 GitHub noreply 주소로 대상 파일만 커밋하고, 일반 fast-forward 푸시를 사용했다. 강제 푸시·계정/Pages 설정 변경은 하지 않았다.

본문 게시 커밋: [`38b72e83696ab3b8612abefe115cbeab751f60fe`](https://github.com/cbh456746/cbh456746.github.io/commit/38b72e83696ab3b8612abefe115cbeab751f60fe).

배포 실행: [GitHub Pages](https://github.com/cbh456746/cbh456746.github.io/actions/runs/40335204516).
