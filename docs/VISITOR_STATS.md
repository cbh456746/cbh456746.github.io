# Home 방문 통계 연결

Home의 `하루의 방문`은 오늘·어제 수치와 최근 7일 막대그래프입니다. 한국 시간으로 날짜를 나누며, 외부 통계 계정이 없거나 연결이 실패하면 실제 수치처럼 보이는 샘플 값을 표시하지 않습니다.

## 실제 집계 시작

1. [GoatCounter 가입](https://www.goatcounter.com/signup)에서 무료 사이트를 만들고 블로그 주소를 등록합니다. 가입 이메일·비밀번호는 이 저장소에 기록하지 않습니다.
2. GoatCounter 설정에서 **Allow adding visitor counts on your website**를 켭니다. 방문 횟수 집계용 **Sessions**는 켜 두고, 개별 방문 기록 저장은 끈 상태를 유지합니다. 불필요한 브라우저·위치·화면 크기 등의 상세 수집도 비활성화할 수 있습니다.
3. `_data/visitor-stats.yml`에 공개 사이트 코드와 집계 시작 날짜만 넣고 `enabled: true`로 바꿉니다. 예를 들어 서비스 주소가 `https://your-code.goatcounter.com`이면 코드는 `your-code`입니다. **API 토큰이 필요하지 않습니다.**
4. 콘텐츠 검사와 테스트 후 게시합니다. 처음 집계한 날 이전의 통계는 소급 복원하지 않습니다.

```yaml
enabled: true
site_code: "your-code"
started_on: "YYYY-MM-DD"
```

위 예시는 실제 계정이 아닙니다. 실제 설정 파일은 계정 정보가 준비될 때까지 비활성 상태로 유지합니다.

## 집계 의미와 개인정보

- 블로그 전체의 페이지 방문을 한국 날짜별 `/daily-visits/YYYY-MM-DD` 경로로 모읍니다. 개별 글 제목·URL 쿼리·해시·유입 주소는 전달하지 않습니다.
- GoatCounter는 약 8시간의 세션 기준으로 같은 경로의 반복 조회를 줄입니다. 사람을 정확히 식별한 일일 고유 인원수는 아니며, 같은 사람이 다른 장치나 새 세션으로 방문하면 추가 집계될 수 있습니다.
- 날짜를 경로에 넣어 한국 자정에 새 날짜로 전환합니다. 전체 누적 카운터 또는 여러 글의 방문 수를 더해 일일 방문자로 표시하지 않습니다. 날짜 필터의 UTC 범위도 사용하지 않습니다.
- 사이트 방문자의 브라우저에 별도 식별 쿠키·localStorage를 만들지 않습니다. 네트워크 접속 시 서비스에 IP와 브라우저 헤더가 전달되는 점과 서비스의 집계 방식을 아래 공식 문서에서 확인할 수 있습니다.
- Do Not Track 또는 Global Privacy Control이 설정된 브라우저에서는 추적과 외부 통계 조회를 생략합니다. 로컬 미리보기·자동 브라우저 검사도 방문 집계에서 제외합니다.
- Home을 자정까지 열어 두거나 잠자기 후 다시 열어도 한국 날짜를 갱신합니다. 그래프 갱신만으로 방문 횟수를 추가하지 않습니다.
- 코드 연결 전에는 외부 서비스 요청을 만들지 않습니다. 공개 카운터 허용만 켜면 되며, 관리자 대시보드를 공개할 필요는 없습니다.
- 외부 스크립트는 GoatCounter v5를 SRI 무결성 값과 함께 불러옵니다. 기본 스크립트가 붙이는 검색 문자열·화면 크기를 제거한 최소 패킷만 전송하며, 봇 판별 값은 유지합니다. 수치 조회에는 인증 토큰·쿠키를 전송하지 않습니다.
- 수치는 서비스 캐시 때문에 최대 약 4시간 지연될 수 있습니다. 처음 등록한 경로도 바로 숫자가 바뀌지 않을 수 있습니다.
- 집계 시작 전 날짜는 `—`, 정상적인 JSON 응답의 0은 `0`, 통신 실패·차단·잘못된 응답은 `—`입니다. HTTP 404라도 GoatCounter의 명시적인 JSON `count: "0"` 응답이면 기록된 방문이 없는 것으로 처리합니다. HTML 404를 0으로 바꾸지 않습니다.
- JavaScript·광고 차단·추적 차단·네트워크 오류 때문에 일부 방문은 집계되지 않을 수 있습니다.

## 확인

```sh
npm run validate
node --test scripts/test-visitor-stats.mjs
```

정상 데이터, 새 집계 날짜, 부분 실패, 서비스 차단, 미연결, 모바일 표시를 검사합니다. 테스트용 숫자와 API 응답은 로컬 검증에서만 사용하며 실제 방문 수로 게시하지 않습니다.
