# 작업실 가독성·미디어·대화 기록 개편 검증

2026-11-05 · M-15 · D-026. 이 기록은 우선 **분리된 복제본의 소스와 자동 검사**를 대상으로 한다. 같은 커밋의 Pages 검증은 배포 후 기록한다.

## 반영한 내용

- 작업실 첫 화면에 세 단계 이용 순서와 사용법·대화 기록 도구의 직접 링크를 둠. 기존 보드·연결 흐름·참고 저장소와 상세 카드 구조는 유지함.
- 작업 상세·요약·상태의 글자 크기와 여백을 조정하고, 프로젝트별 공개 사진·영상 카드와 대체 설명·영상 표지를 추가함.
- `/workbench/guide/`를 실제 조작 순서로 재작성하고 기능 지도를 넣음.
- `/workbench/records/`에 턴별 대화 전문, 별도 선별 프롬프트, 턴 출처, JSON 저장·재열기를 제공함. 입력은 페이지 메모리에만 두고 공통 통계·사이트 스크립트와 분리함.
- 공개 상태 스키마에 안전한 정적 미디어 경로 검사를 추가함. 개인 대화 원문은 상태 JSON·Git 기록에 넣지 않음.

## 후속 확인 순서

1. 현재 작업 트리의 다른 미게시 변경(M-14)을 보존하고 M-15 변경과 검토 범위를 분리한다.
2. Jekyll로 Home·작업실·사용법·대화 기록 도구를 실제 렌더한다. 생성된 상태 JSON이 같은 revision인지 확인한다.
3. PC와 390px 모바일에서 작업 카드·갤러리·영상 조작·사용법 링크·대화 편집·JSON 다운로드/재열기를 확인한다. 빈 상태와 잘못된 JSON, 페이지 이탈 경고도 시험한다.
4. 공개 파일과 Git 차이를 개인정보·자격 증명·개인 경로·불필요한 자료 관점에서 검수한다. 개인 기록 파일을 저장소에 추가하지 않는다.
5. M-14의 미게시 변경을 제외한 이 복제본을 일반 fast-forward로 게시한 뒤 같은 SHA의 Actions, 실제 공개 페이지와 미디어 응답을 확인한다.

이 단계를 마치기 전에는 M-15의 시각·배포 완료를 주장하지 않는다. JSON 편집 도구는 비공개 저장소 동기화나 Codex 대화 자동 수집 기능이 아니며, 저장 파일을 AI가 나중에 읽으려면 소유자가 제공하거나 권한 있는 비공개 저장소 접근이 필요하다.
