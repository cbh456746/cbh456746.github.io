대화는 턴별로,
프롬프트는 따로.

한 프로젝트에서 AI와 나눈 대화를 순서대로 보존하고, 다시 쓸 프롬프트만 별도로 골라 저장합니다. 내용은 이 브라우저에서 편집한 뒤 JSON 파일로 내려받습니다.

개인 기록 보관 안내

이 페이지에는 계정 로그인이나 서버 저장 기능이 없습니다. 입력 내용은 사이트에 전송하거나 공개 작업 데이터에 합치지 않습니다. 파일은 직접 내려받아 비공개 저장소나 개인 보관 위치에 두세요. 공용 PC나 믿을 수 없는 브라우저에서는 사용하지 마세요.
