# Contribution and review checklist

Before publishing, confirm:

- the agent read AGENTS.md, whole-blog operations, recent decisions and the actual repository state;
- the intended scope and existing publication authorization are honored;
- this task's Currently exploring metadata, actual summary and relevant cards are updated and render correctly;
- the file is in the correct content folder;
- title, date, and tags exist;
- `Blog` does not appear as a tag;
- Game entries also use Play;
- links and images point to the intended files;
- reviewed context summaries, appendices and source-version links preserve the original results and limitations;
- private sources, credentials, personal paths and unapproved profile fields are absent from public changes;
- the mobile layout has been checked in Edge DevTools or a phone;
- GitHub Actions is green after push.
- the successful workflow belongs to the exact published SHA and the changed public page/files were checked;
- the final report distinguishes completed work, unverified claims and follow-up tasks.

Routine implementation and publication are agent-operated. A task can contain follow-up verification commits; those belong to the same current-work entry. Automatic validation checks only part of this list. It does not establish that a claim is true or that every task was recorded.
